🌌 Abyss

An independent Android customization project for Among Us.

Abyss is an Android-based modification project focused on client-side visual customization, display configuration and frame rate adjustments.

✨ Features

- 🎭 Visual Customization
  
  - Local cosmetic visualization.
  - Client-side cosmetic previews.
  - No changes to account ownership or server-side entitlements.

- 📱 Display Configuration
  
  - Custom screen resolution.
  - Adjustable display quality.
  - Visual configuration options.

- ⚡ Performance Settings
  
  - Uncapped frame rate option.
  - Customizable FPS settings.
